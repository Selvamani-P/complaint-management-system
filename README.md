# Complaint Management System

A full-stack Complaint Management System built with React and Spring Boot.

## Tech Stack

### Frontend
- React
- JavaScript
- CSS
- Axios
- React Router

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- MySQL

## Features

- User registration and login
- JWT-based authentication
- Complaint creation and management
- Complaint assignment
- Complaint status updates
- Complaint details and history
- Employee task management
- Notifications
- User management
- Reports and dashboard
- Role-based access control
